CCS Department Club Member Management System - CLEAN SETUP
==============================================================

1. Database
-----------
Create a MySQL database named:
    SchoolClubManagement

Set your .env:
    DB_CONNECTION=mysql
    DB_HOST=127.0.0.1
    DB_PORT=3306
    DB_DATABASE=SchoolClubManagement
    DB_USERNAME=root
    DB_PASSWORD=

2. Laravel
----------
Run inside this CCS folder:

    composer install
    copy .env.example .env
    php artisan key:generate
    php artisan migrate
    php artisan optimize:clear
    php artisan storage:link

3. Create Admin
---------------
Run:
    php artisan tinker

Then:
    \App\Models\User::updateOrCreate(
        ['email' => 'admin@gmail.com'],
        [
            'name' => 'Administrator',
            'email' => 'admin@gmail.com',
            'password' => 'tmc12345',
            'role' => 'admin',
            'email_verified_at' => now(),
        ]
    );

Exit:
    exit

Admin login:
    Email: admin@gmail.com
    Password: tmc12345

4. Front-end assets
-------------------
The archive intentionally does NOT include node_modules because that copied
node_modules tree can contain the wrong platform binaries/permissions.

Run:
    npm install
    npm run dev

Or for a production build:
    npm run build

Keep "npm run dev" running while developing. The Blade layout now checks
for a Vite hot file/manifest before calling @vite, so a missing Vite server
does not produce a Laravel 500 error.

5. Leave Request flow
---------------------
Student mobile API:
    POST /api/leave-requests
    GET  /api/leave-requests/my

Web review:
    GET  /leave-requests
    POST /leave-requests/{leaveRequest}/approve
    POST /leave-requests/{leaveRequest}/decline

Approving a request changes the old membership to inactive. The student
can then apply to another club. Notification status is exposed through
the existing notification API.

6. Clear caches after replacing files
-------------------------------------
    php artisan optimize:clear
    php artisan route:list

If "club_leave_requests" is not yet present:
    php artisan migrate

7. If npm reports missing optional Rollup packages
---------------------------------------------------
Delete node_modules and run:
    npm install

Do not reuse a node_modules folder copied from another operating system.
